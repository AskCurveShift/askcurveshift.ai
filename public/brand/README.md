# Curve Shift identity

The mark uses two rising curves to express a shift in growth trajectory. The wordmark is outlined vector artwork based on Mona Sans, matching the site typography.

- curve-shift.svg / curve-shift.png: transparent dark primary lockup.
- curve-shift-reversed.svg / curve-shift-reversed.png: transparent white lockup for dark backgrounds.
- curve-shift-mark.svg / curve-shift-mark-reversed.svg: standalone symbols.
- ../icon.svg, ../favicon-32.png, ../apple-touch-icon.png: application icons.
- ../social-preview.svg / ../social-preview.png: 1200 × 630 sharing artwork.

Primary: #171717. Background: #ffffff. Secondary text: #666666.

Keep clear space around the mark. Preserve proportions. Use the standalone symbol at small sizes. Avoid blue tints or gradients.
