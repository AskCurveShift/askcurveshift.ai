# Curve Shift public website

This is the public deployment checkout. Keep unpublished drafts, private briefs, research notes, credentials, and local preview content in the separate local authoring project.

Preserve the existing Steady pages in `public/steady/`. Netlify publishes the static `out/` export on pushes to `main`; retain the static export and security headers. Run `npm run typecheck` and `npm run build` before pushing website changes.
